# SkyCast – Weather App

A lightweight, responsive web application that displays real-time weather metrics for any searched city using open-access APIs.

### Concepts Implemented
- **Asynchronous JavaScript:** Non-blocking operations using `async/await` syntax.
- **Fetch API:** Consuming remote REST endpoints and parsing JSON data without external libraries.
- **Error Handling:** Graceful failure interception with `try/catch` blocks to handle invalid inputs, empty queries, and network drops without UI crashes.

### Tech Stack
- HTML5
- CSS
- JavaScript
- [Open-Meteo API](https://open-meteo.com/) (Geocoding & Weather Data)
